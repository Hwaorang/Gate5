# Changelog

## 1.1.0 - 2026-09-03

- 이전 판정 연동 API와 관련 예제 제거
- `Play`를 위치, 방향, 시각 거리만 받는 순수 발사 연출로 변경
- 피격 spark를 독립적으로 호출하는 `PlayImpact` 추가

## 1.0.0 - 2026-09-03

- Unity 6000.3용 pooled multi-tracer, muzzle flash, impact spark 추가
- 물리 또는 충돌 의존성이 없는 순수 시각 효과 API 추가
- 발사 효과와 피격 효과를 독립된 호출로 분리
- URP 및 Built-in runtime shader fallback 추가
- Quick Start 예제와 한국어 사용 문서 추가
