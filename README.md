2조 Gate5 팀프로젝트

1. 게임 소개
 - 장르: 3D 캐주얼 러너 / 슈팅
 - 엔진/언어: Unity / C#
 - 게임 설명: 
   상단에서 내려오는 게이트를 통과하여 플레이어 인원을 증식하고,
   좀비를 물리쳐 얻은 경험치로 레벨업하며 끝까지 살아남는 게임입니다.
   게임 종료 후 획득한 골드로 로비에서 능력치를 강화할 수 있습니다.

2. 조작법
 - UI 상호작용: 마우스 좌클릭
 - 플레이어 이동: A, D 키
 - 일시정지 / 메뉴: Esc 키
 - 인게임 카메라 시점변경: F10 키


3. 게임 규칙 및 핵심 시스템
 - 승리 / 패배 조건: 플레이어 수(인원)가 0이 되면 게임 오버
 - 게이트 시스템: +, - 게이트 통과 시 플레이어 수 변동
 - 레벨업 시스템: 좀비 처치 시 경험치 획득 -> 일정 경험치 도달 시 레벨업 및 강화 선택
 - 성장 시스템: 게임 종료 후 획득한 골드를 사용해 로비에서 플레이어 영구 강화

4. 실행 환경
 - 권장 해상도: 1920 x 1080
